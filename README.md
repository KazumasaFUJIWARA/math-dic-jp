# math-dic-jp — 数学用語 IME 辞書

標準の IME では変換できない、あるいは誤変換される数学用語を登録するためのユーザー辞書です。

- 専門用語：`かかい` → 下界、`しょうさんがた` → 消散型、`ぜんきんけい` → 漸近形
- 数学で使われる異体字：`ほうぶつせん` → 抛物線、`きょうやく` → 共軛、`かんすう` → 函数、`べききゅうすう` → 冪級数・羃級数・巾級数
- 外国人名の原語表記：`しゅれでぃんがー` → Schrödinger、`ゔぁいえるしゅとらす` → Weierstraß
- 日本人数学者名：`いわさわ` → 岩澤、`くまのごう` → 熊ノ郷

本体の辞書には用語約 6,300 語と人名約 1,800 件（約 1,500 表記）が入っています。
現在は Windows（Microsoft IME）用のみです。

## Windows（Microsoft IME）への適用

Windows 10 / 11 標準の Microsoft IME のユーザー辞書に、テキストファイルから一括で登録します。

### 1. 辞書ファイルを保存する

[`dist/windows/math-dic-ms-ime.txt`](dist/windows/math-dic-ms-ime.txt) を開き、右上の「Download raw file」（↓のアイコン）で保存します。
リポジトリ全体なら、トップページの「Code」→「Download ZIP」でも入手できます。

> ブラウザーに表示された中身をコピーしてメモ帳に貼り付けるのではなく、ファイルのまま保存してください。
> 辞書ファイルは UTF-16（BOM 付き）で、貼り付け直すと文字コードが変わって取り込めなくなることがあります。

### 2. ユーザー辞書ツールを開く

次のどちらかで開きます。

- **IME のメニューから**：タスクバー右下の「あ」または「A」を右クリック →「単語の追加」→ 開いた「単語の登録」ウィンドウ左下の「ユーザー辞書ツール」
- **設定から（Windows 11）**：設定 → 時刻と言語 → 言語と地域 → 日本語の「…」→ 言語のオプション → キーボードの「Microsoft IME」の「…」→ キーボード オプション → 学習と辞書 →「ユーザー辞書ツールを開く」
- **設定から（Windows 10）**：設定 → 時刻と言語 → 言語 → 日本語 →「オプション」→ Microsoft IME の「オプション」→ 学習と辞書 →「ユーザー辞書ツールを開く」

### 3. 今のユーザー辞書を控えておく（おすすめ）

ユーザー辞書ツールのメニュー「ツール」→「一覧の出力」で、今のユーザー辞書をテキストファイルに保存しておきます。
この辞書を丸ごと外したくなったときに、元の状態へ戻せます（「元に戻す」を参照）。

### 4. 取り込む

1. ユーザー辞書ツールのメニュー「ツール」→「テキスト ファイルからの登録」を選ぶ。
2. 手順 1 で保存した `math-dic-ms-ime.txt` を選んで「開く」。
3. 8,000 語ほどあるので、終わるまで少し時間がかかります。
4. 終わると、登録できた語の数と登録できなかった語の数が表示されます。登録できなかった語は、表示されるログで確かめられます。

### 5. 確かめる

メモ帳などで次のように入力して変換し、候補に出れば登録できています。

| 入力 | 候補 |
|------|------|
| かかい | 下界 |
| しょうさんがた | 消散型 |
| しゅれでぃんがー | Schrödinger |
| ゔぁいえるしゅとらす（vaierusyutorasu と入力） | Weierstraß |

登録した語は、最初のうちは候補の下のほうに出ることがあります。一度選ぶと IME が学習して上に出るようになります。

### 新しい版に更新する

新しい `math-dic-ms-ime.txt` を保存して、手順 4 と同じように取り込みます。
すでに登録されている語は「登録できなかった語」として数えられますが、新しく増えた語は登録されます。
版の間で削除・修正された語を消したいときは、「元に戻す」の手順で一度外してから取り込み直してください。

### 元に戻す

- **一部の語だけ消す**：ユーザー辞書ツールの一覧で語を選び（Ctrl や Shift を押しながら複数選べます）、Delete キーで削除します。
- **丸ごと外す**：一覧で Ctrl+A を押してすべて選んで削除し、手順 3 で控えたファイルを「テキスト ファイルからの登録」で取り込み直します。この操作は自分で登録した語もいったん消すので、必ず控えを取ってから行ってください。

### うまくいかないとき

- **「ヴぁ…」「ゔぁ…」で始まる読みの行だけがエラーになる**：問題ありません。どちらか一方が登録されていれば引けます（「ヴ」の読みについて を参照）。
- **人名・さ変名詞・形容動詞の語がまとめてエラーになる**：品詞名を受け付けない版の IME です。品詞をすべて「名詞」にしたファイルを作り直して取り込んでください（「語の追加・修正」の `--pos-simple` を参照）。
- **ファイルを選んでも何も登録されない／文字化けする**：ファイルをコピー＆ペーストで作り直していないか確認し、手順 1 の方法で保存し直してください。

### 追加辞書（必要な人だけ）

日常語と読みが重なる語を含むので、本体とは別のファイルにしてあります。本体と同じ手順で取り込めます。

| ファイル | 内容 |
|---------|------|
| [`dist/windows/math-dic-ms-ime-kyuji.txt`](dist/windows/math-dic-ms-ime-kyuji.txt) | 旧字体（函數、收斂、雙曲線、楕圓、連續、寫像、對稱 など）。戦前の文献の書名・引用用。`かんけい` → 關係 のように日常語の読みにも旧字体が出るようになります。 |
| [`dist/windows/math-dic-ms-ime-wasan.txt`](dist/windows/math-dic-ms-ime-wasan.txt) | 和算の用語と和算書の書名（点竄術、天元術、算額、塵劫記 など）。 |

### 「ヴ」の読みについて

Microsoft IME は、2020 年以降の版ではひらがな入力中の `vu` を `ゔ` に、それより前の版では `ヴ` にします。
どちらでも引けるように、`ゔ` を含む読みには `ヴ` の読みも登録してあります
（例：`ゔぁいえるしゅとらす` と `ヴぁいえるしゅとらす` → Weierstraß）。
お使いの IME が片方の読みを受け付けない場合、その行は登録時のログにエラーとして出ますが、ほかの語は登録されます。

### 日常語との衝突について

`ゆうかい` → 有界（誘拐）、`せいじ` → 斉次（政治）のように、数学用語が日常語と同じ読みになることは避けられません。
一字だけの語（系、元、像、法 など）のように、もともと IME で変換できて衝突だけが増える語は入れていません。
邪魔な語があれば、ユーザー辞書ツールでその語だけ削除してください。

## 語の追加・修正

`data/` 以下の TSV を編集して、生成スクリプトを実行します。書式は [CONTRIBUTING.md](CONTRIBUTING.md) を見てください。

```
python3 tools/build.py
```

検査（読みにひらがな以外が混じっていないか、品詞名が正しいか等）を通ると `dist/` が更新されます。

登録時に品詞（人名・さ変名詞・形容動詞）のエラーが出る場合は、品詞をすべて「名詞」にして生成し直せます。

```
python3 tools/build.py --pos-simple
```
